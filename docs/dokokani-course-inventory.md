# どこかにビューーン！駅別モデルコース制作台帳

最終確認：2026-11-24。各駅につき最低1本の独立したモデルコースを用意する。既存記事は内容を確認して活用する。駅ガイドやスポット単体の記事はモデルコースに数えない。

## 対象と数え方

制作の第一範囲は、JR東日本が2025年10月に公表した首都圏発グリーン車版の行き先候補46駅（ガーラ湯沢を含む）。ガーラ湯沢は営業期間中のみ候補となる。駅の一覧は[JR東日本の発表資料](https://www.jreast.co.jp/press/2025/20251023_ho03.pdf)による。普通車の対象・地方発の候補は別途最新情報を確認する。地方発では東京・上野・大宮を含む候補があり得るため、46駅が全出発駅の行き先の総数を意味するものではない。[商品案内](https://www.eki-net.com/top/product/shinkansen/e-dokokani.html)

「既存」はファイルの存在と対象駅を確認した状態で、交通・営業時間等の最新性を検証済みという意味ではない。「未着手」はファイル名や既存駅データから専用コースを確認できなかった暫定状態であり、制作前に全記事を再検索する。

## 制作・確認

- 旅程ごとに出発駅、日数、交通手段、対象日または適用期間を明示し、往復の乗継、最終便、施設の営業、予算を公式情報と照合する。
- 実際の指定列車は申込後に決まるため、想定する到着・出発時間帯と、条件に合わない場合の調整方法を示す。
- 宿泊・交通・入場・食事の費用を区分し、ポイントと現金を混同しない。未確認の料金・交通は捏造しない。
- 完成後は駅ページのデータと実在するモデルコースへの導線を整備する。`dokokanibyun.ts` は現時点で上記全駅を網羅していないため、未登録駅は別途実装が必要。
- 確認済みの公式資料、確認日、対象期間と未解決事項を各記事に残す。写真や宿の予約リンクは実在と利用条件を確認する。
